# Timer App - モダンポモドーロタイマー

## 📖 概要

Timer Appは、生産性向上のためのモダンなポモドーロタイマーアプリケーションです。HTML、CSS、JavaScriptを使用して構築されており、美しいUI/UXと実用的な機能を提供します。

## ✨ 主な機能

- **カウントダウンタイマー**: 作業時間と休憩時間のカウントダウン
- **セッション管理**: 作業セッションと休憩セッションの自動切り替え
- **プログレスリング**: 視覚的な進捗表示
- **カスタマイズ可能**: 作業時間と休憩時間の設定
- **通知機能**: 音声とビジュアル通知
- **セッションカウンター**: 完了したセッション数の記録
- **ローカルストレージ**: 設定とセッション数の永続化
- **キーボードショートカット**: スペースキー（開始/一時停止）、Escキー（リセット）
- **レスポンシブデザイン**: モバイルフレンドリーなUI
- **ダークモード対応**: システム設定に応じた自動切り替え

## 🚀 使用方法

### 基本操作

1. **タイマー開始**: 「開始」ボタンをクリックまたはスペースキーを押す
2. **一時停止**: タイマー実行中に「一時停止」ボタンをクリックまたはスペースキーを押す
3. **リセット**: 「リセット」ボタンをクリックまたはEscキーを押す

### 設定

- **作業時間**: 1-60分の範囲で設定可能（デフォルト: 25分）
- **休憩時間**: 1-30分の範囲で設定可能（デフォルト: 5分）

### キーボードショートカット

- `スペースキー`: タイマーの開始/一時停止
- `Escキー`: タイマーのリセット

## 🛠️ 技術仕様

### 使用技術

- **HTML5**: セマンティックなマークアップ
- **CSS3**: モダンなスタイリング（CSS Grid、Flexbox、CSS Variables）
- **JavaScript (ES6+)**: アプリケーションロジック
- **Web APIs**: Audio Context、Page Visibility、Local Storage

### ブラウザサポート

- Chrome/Edge 60+
- Firefox 55+
- Safari 12+
- モバイルブラウザ対応

## 🧪 テスト

アプリケーションには包括的なテストスイートが含まれています。

### テスト実行方法

1. `test.html`をブラウザで開く
2. 「テストを実行」ボタンをクリック
3. コンソールでテスト結果を確認

### テスト内容

- **ユーティリティ関数**: 時間フォーマット、入力検証、進捗計算
- **ローカルストレージ**: 設定とセッション数の永続化
- **ブラウザ機能**: Web API の可用性チェック
- **UI インタラクション**: キーボードショートカット、ボタン状態

## 🔧 開発

### ローカル開発

1. リポジトリをクローン
2. `index.html`をブラウザで開く
3. 開発者ツールでデバッグ

### 本番ビルド

このアプリケーションは静的ファイルのため、ビルドプロセスは不要です。ファイルをWebサーバーにデプロイするだけで動作します。

## 📱 PWA対応（オプション）

Service Workerの実装により、PWA（Progressive Web App）としての機能追加が可能です。

## 🐛 既知の問題

- Safari での Audio Context の制限により、音声通知が動作しない場合があります
- iOS Safari でのタブ切り替え時の動作に制限があります
